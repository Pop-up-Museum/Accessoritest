# [BRAND] · Liber Armorum

Sito vetrina (una pagina) della scatola-tappetino e dei quattro regni.

## Pubblicare con GitHub Pages
1. Crea un nuovo repository su GitHub (anche privato, se il tuo piano lo consente per Pages).
2. Carica tutto il contenuto di questa cartella nella radice del repository (Add file → Upload files, trascinando le cartelle `img2` e `anim` insieme a `index.html`).
3. Vai in **Settings → Pages**, alla voce *Source* scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, e salva.
4. Dopo un minuto il sito è online all'indirizzo `https://<tuo-utente>.github.io/<nome-repository>/`.

## Contenuto
- `index.html` – la pagina (HTML, CSS e JavaScript in un unico file)
- `img2/` – render dei quattro regni e logo
- `anim/` – 90 fotogrammi dell'animazione di apertura
- `.nojekyll` – dice a GitHub Pages di servire i file così come sono

I font (Grenze Gotisch, IM Fell English) arrivano da Google Fonts: serve la connessione a internet.
